# FREE-WILi 2 Mounting Files

Mechanical reference files for mounting a FREE-WILi 2 to an enclosure, bracket, or custom accessory.

## Files

| File | What it is |
| --- | --- |
| `FreeWili2-Mount-Locations.pdf` | Dimensioned drawing of the mounting-hole pattern (Rev A, 2026-09-18). |
| `FreeWili2-Mount-Template.step` | STEP AP214 solid of the mount template, exported from SolidWorks 2026. Use this for CAD. |
| `FreeWili2-Mount-Template.stl` | Binary STL of the same template. Use this for 3D printing a test fixture or for viewers that do not read STEP. |

## Key dimensions

All dimensions are in millimeters.

| Feature | Value |
| --- | --- |
| Mounting holes | 3x M3 threaded |
| Hole pattern, horizontal span | 131.50 |
| Hole pattern, vertical span | 63.30 |
| Offset to mid-height hole | 40.30 |
| Template overall envelope (L x W x T) | 141.9 x 73.7 x 6.5 |

See the PDF drawing for the full hole layout, including the unthreaded locating holes and the outline of the FREE-WILi 2 body.

## How to use

1. Open the STEP file in your CAD tool (SolidWorks, Fusion 360, FreeCAD, Onshape) and use it as a reference body or a cut tool for your enclosure.
2. Print the STL at 100% scale to check hole alignment against a real FREE-WILi 2 before committing to a machined or molded part.
3. Fasten with M3 screws into the three threaded holes. Confirm screw length against your own bracket thickness so the screws do not bottom out in the device.
